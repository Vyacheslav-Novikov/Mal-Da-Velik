# Сайт «Мал да велик»

Для локального просмотра запустите `python3 -m http.server 4173 --bind 127.0.0.1 --directory site`.

## Публикация

GitHub Actions публикует папку `dist/` с предпросмотром. В настройках GitHub Pages в качестве источника выберите **GitHub Actions**. Сборка для предпросмотра добавляет `noindex` ко всем HTML-страницам и настраивает карточки для пересылки ссылки.

Для постоянного сайта используйте Python 3.9 или новее и подставьте подтверждённый домен клиента вместо `example.com`.

```sh
python3 scripts/build-site.py https://example.com/ dist --production
```

Сборка создаёт `dist/` с каноническими адресами страниц, разметкой филиалов, `sitemap.xml` и `robots.txt`. Опубликуйте содержимое папки в корне постоянного домена. При переносе существующего сайта сопоставьте его индексируемые адреса с новыми страницами, настройте постоянные перенаправления и отправьте карту сайта в Яндекс Вебмастер и Google Search Console после проверки домена.
